## Products & Services

This submission funds the development of our B2B "Collective Investment" plug-and-play module within the Escala Cloud Studio. Specifically, it will add:

1.  **Soroban Core Contracts:** A Treasury Contract for USDC escrows and a Voting Contract using Soulbound Tokens (SBTs) for on-chain governance.
    
1.  **B2B AI UI/UX Dashboard:** A visual interface for NGOs and cooperatives to seamlessly deploy and manage these funds.
    
1.  **Ecosystem Integrations:** Native API connections with MoneyGram and others rails (Cash-in/out) and Circle (USDC) for abstracting crypto complexities from end-users. Also the connection with the Stellar Disbursement Platform.
