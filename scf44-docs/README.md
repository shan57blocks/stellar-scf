# SCF #44 Project Documents

Documents for the 32 SCF #44 projects that have public code (see [../scf44-open-source.md](../scf44-open-source.md)). Collected 2026-09-24.

- `README.md`: plain-language overview, what SCF #44 pays them to build (tranches), how it works, a table of every document found, and gaps.
- `submission.md`: the official SCF #44 proposal text, copied from the submission page. This is the initial requirements document: deliverables, completion criteria and budget per tranche.
- Local text copies of the key documents. Each copy's first line gives its source URL. Diagrams inside documents are images and are usually not in the text copies.
